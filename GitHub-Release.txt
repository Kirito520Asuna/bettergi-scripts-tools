版本详情:

## ✨ 新功能

- **圣遗物强化语法可视化配置**：新增“语法配置中心”页面，支持花/羽/沙/杯/冠五种部件类型的可视化编辑，提供主词条和副词条的属性筛选（含生命%、攻击%、防御%等新属性），实时生成强化语法并提供预览和复制功能。
- **数据备份与恢复体系**：
  - 实现本地与远程备份的全流程管理：自动备份、备份列表分页查询、按 ID 下载备份文件。
  - 支持在线恢复（本地文件上传或远程记录恢复），恢复前增加确认对话框以规避误操作。
  - 提供批量删除功能，可多选远程或本地备份并一键清理。
  - 备份文件命名增加随机字符串，防止重名覆盖。
- **用户信息接口**：新增 `/auth/info/username` 接口获取当前登录用户名，前端设置页面在重置用户表单时自动预填用户名。
- **通用分页组件**：引入 PageHelper 分页插件，封装 `AbsPage` 接口和 `ResultPage` 类，为后续列表分页提供统一返回格式。
- **定时任务动态调度**：创建 `sys_job` 表，支持通过数据库配置动态注册 Quartz 定时任务，与系统级任务共存，方便未来扩展定时备份等功能。

## 🔧 改进与重构

- 数据库配置结构由 `datasource.dynamic` 简化为 `db` 配置块，支持主数据库类型快速切换。
- `SysJob` 实体全面迁移至 MyBatis Plus，服务层代码更简洁，查询方式统一为 LambdaWrapper。
- 备份下载逻辑改为支持按 ID 获取历史备份，文件下载增加多线程分片传输以应对大文件场景。
- 前端路由权限：修复开发模式下可能绕过路由守卫的安全隐患，确保生产和开发环境行为一致。
- 设置页面重构为弹窗模式（用户信息、Token 修改、备份管理均弹出独立对话框），页面结构更清晰。

## 🎨 样式与交互优化

- 全局隐藏滚动条并保持滚动能力，提升视觉沉浸感。
- UID 管理页和 WebSocket 代理授权页采用动态标题、响应式布局，适配移动端，并优化按钮悬停效果。
- 页面头部采用渐变文字、模糊背景、圆角阴影等现代化设计。
- 按钮样式作用域限定在容器内，避免样式污染；固定底部导航按钮样式统一。
- 拖拽上传区域增加图标视觉提示，并完善拖拽高亮交互。

## 🐛 修复

- 修复设置页面用户信息重置时未清空密码导致残留数据的问题。
- 修复备份恢复弹窗中部分样式和事件处理逻辑缺失导致的界面异常。
- 修复开发环境 API 路径配置错误导致请求跨域失败的问题。
- 修复滚动条样式在不同浏览器下不一致的问题。
