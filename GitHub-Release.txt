### 版本变更详情

#### ✨ 新功能
    - 生成器模块：新增 BAT 脚本生成功能，支持配置 1Remote 自启动脚本参数（标题、目录、ULID、等待时间等），并提供预览、下载和复制内容功能。
    - 文件名与 ULID 帮助：在生成器界面为 fileName 和 startUlid 字段添加帮助图标，点击可查看自启动步骤说明和 ULID 获取步骤。
    - 1Remote 版本管理：集成 GitHub 远程标签接口，在生成器页面新增“1Remote 版本”按钮，展示所有版本及文件列表，支持直接下载和代理下载。
    - API 接口扩展：新增获取 1Remote 所有版本信息接口 /github/1Remote/tags；重构 GitHub 工具类，新增获取 workflows、runs、artifacts 以及所有 Release 信息的方法。
    - 功能分组过滤：主页功能支持按环境（dev/prod）过滤分组显示，演示 分组仅在开发环境显示。
    - 体力计划 JS 入口：在自动计划配置界面新增“体力计划 JS”项，提供前往 bgi 仓库订阅的快捷入口，并重构 API 列表为网格布局，优化移动端显示。
    - 数据库初始化结构：定义数据库脚本相关的记录类（SqlFormat、DbScript、ColumnSql 等），为后续数据库初始化提供标准化数据结构。
    - 首页快捷入口：系统分组中添加“BGI 仓库”外部链接，方便快速访问 bgi.sh。
#### 🐛 修复
    - 路由分组与名称：修正 AutoPlanDomain 页面的分组名称为“配置分析”，统一 Bgi 仓库 链接的大小写格式为“BGI 仓库”。
    - 下载空内容问题：修复生成器下载时内容为空导致失败的问题，下载前若内容为空会自动调用预览获取内容。
    - 配置 ID 重复：将随机 ID 生成算法从 9 位改为 8 位并添加 "T" 后缀，降低配置 ID 重复概率。
#### 🔧 改进与重构
    - 生成器界面优化：重构文件夹选择对话框状态管理，使用 try-finally 确保状态正确重置；优化整体布局和响应式设计，适配移动端。
    - GitHub 工具类重构：将 BatGenerator 重命名为 Generator；分离 GitHub API 请求逻辑，新增多个静态方法以支持 workflow、run、artifact 和全部 release 的查询与下载。
    - 前端导航优化：在生成器和自动计划页面底部统一添加“返回上一页”和“返回主页”按钮，改善页面间跳转体验。
    - API 展示界面重构：自动计划配置的 API 弹窗改为网格布局，增加权限控制（auth_copy）隐藏无权限项目的复制按钮，优化空状态提示和滚动条样式。
    - 环境配置变量：新增 VITE_BASE_ENV 环境变量，用于控制功能分组在不同环境下的可见性。
    - 代码注释完善：为数据库脚本相关记录类添加详细 JavaDoc 注释；移除未使用的导入和注解，优化代码格式。
