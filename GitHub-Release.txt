版本详情:

## ✨ 新功能

- **圣遗物强化语法可视化配置**：新增“语法配置中心”页面，支持花/羽/沙/杯/冠五种部件类型的可视化编辑，提供主词条和副词条的属性筛选（含生命%、攻击%、防御%等新属性），实时生成强化语法并提供预览和复制功能。
- **数据备份与恢复体系**：
  - 实现本地与远程备份的全流程管理：自动备份、备份列表分页查询、按 ID 下载备份文件。
  - 支持在线恢复（本地文件上传或远程记录恢复），恢复前增加确认对话框以规避误操作。
  - 提供批量删除功能，可多选远程或本地备份并一键清理。
  - 备份文件命名增加随机字符串，防止重名覆盖。
- **用户信息接口**：新增 `/auth/info/username` 接口获取当前登录用户名，前端设置页面在重置用户表单时自动预填用户名。
- **通用分页组件**：引入 PageHelper 分页插件，封装 `AbsPage` 接口和 `ResultPage` 类，为后续列表分页提供统一返回格式。
- **定时任务动态调度**：创建 `sys_job` 表，支持通过数据库配置动态注册 Quartz 定时任务，与系统级任务共存，方便未来扩展定时备份等功能。
- 日志查看器实时推送：全新的 WebSocket 日志查看页面，支持选择日志文件、行数，实时接收日志内容，并支持历史文件展示。
- 多应用实例日志隔离：支持在集群/多实例环境下选择不同应用实例，查看对应日志；WebSocket 连接按实例 + 用户分组，防止串台。
- 日志访问令牌机制：前端获取专用 LogKey 令牌（有效期 1 天），WebSocket 握手基于令牌 + 应用 ID 双重验证，不再依赖原有登录 Token，更安全。
- 令牌自动续期：WebSocket 连接建立时若令牌即将过期（<30 分钟），自动生成新令牌并推送给前端，前端无感续期，日志连接不中断。
- 过期令牌自动清理：通过定时任务定期扫描并删除已过期的日志令牌，避免数据膨胀。
- 链路追踪与 MDC 传递：新增 TraceFilter，为每个请求生成 traceId 并写入 MDC；定义 mdcTaskExecutor 线程池，自动将父线程 MDC 上下文传递至子线程，确保异步任务日志关联。
- 日志文件滚动与保留策略：生产环境日志按大小（10MB）和时间（天）滚动，保留 30 天历史，总容量上限 1GB，防止磁盘写满。
- 文件列表超时轮询：前端获取日志文件列表时，若当前应用未成功获取，会进行超时控制（最多 3 分钟）和 2 秒间隔重试，确保最终拿到正确列表。


## 🔧 改进与重构

- 数据库配置结构由 `datasource.dynamic` 简化为 `db` 配置块，支持主数据库类型快速切换。
- `SysJob` 实体全面迁移至 MyBatis Plus，服务层代码更简洁，查询方式统一为 LambdaWrapper。
- 备份下载逻辑改为支持按 ID 获取历史备份，文件下载增加多线程分片传输以应对大文件场景。
- 前端路由权限：修复开发模式下可能绕过路由守卫的安全隐患，确保生产和开发环境行为一致。
- 设置页面重构为弹窗模式（用户信息、Token 修改、备份管理均弹出独立对话框），页面结构更清晰。
- 日志核心逻辑从控制器剥离至 LogsService 服务层，后续可复用并支持事务管理。
- WebSocket 连接池键值从用户名重构为 applicationId（或 applicationId:username），移除对用户名的强依赖，适配多实例场景。
- 前端日志 API 独立为 @api/log/log.js 模块，分离文件列表获取和授权令牌获取接口，职责更清晰。
- 前端自动加载间隔从 3 秒调整为 10 秒，减少服务器压力。
- WebSocket 握手拦截器增强：提取 applicationId 参数并存入会话属性，支持实例匹配和非命中反馈。
- 后端参数提取方法重构为通用 extractParameter，提高代码复用性。
- LogKey 实体用于管理日志令牌，数据存储在 DbKV 表中，增删改查逻辑完整实现。

## 🎨 样式与交互优化

- 全局隐藏滚动条并保持滚动能力，提升视觉沉浸感。
- UID 管理页和 WebSocket 代理授权页采用动态标题、响应式布局，适配移动端，并优化按钮悬停效果。
- 页面头部采用渐变文字、模糊背景、圆角阴影等现代化设计。
- 按钮样式作用域限定在容器内，避免样式污染；固定底部导航按钮样式统一。
- 拖拽上传区域增加图标视觉提示，并完善拖拽高亮交互。

## 🐛 修复

- 修复设置页面用户信息重置时未清空密码导致残留数据的问题。
- 修复备份恢复弹窗中部分样式和事件处理逻辑缺失导致的界面异常。
- 修复开发环境 API 路径配置错误导致请求跨域失败的问题。
- 修复滚动条样式在不同浏览器下不一致的问题。
- 修复日志密钥过期时间单位错误，将有效期从 30 分钟修正为 1 天，避免频繁过期。
- 修复文件列表未按应用实例隔离的问题，现在选择不同实例会清空并重新获取对应的文件列表。
- 修复应用切换时文件列表清空和自动加载逻辑不匹配的问题，保证状态同步。
- 修复部分情况下 WebSocket 连接重试机制未正确触发的问题，增加实例未命中后的自动重试。
- 开发环境中排除 Undertow 依赖冲突，保证 WebSocket 功能正常启用。
